# Task Board ⚡

A task management board built with React and TypeScript, featuring full CRUD operations and a Solo Leveling inspired "System" theme.

## 🔗 Live Demo
[View Live Project](https://task-board-xi-eight.vercel.app/)

## ✨ Features
- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Toggle task completion (done / not done)
- 🔢 Live task counter (total & completed)
- 🛡️ Input validation (prevents empty tasks)
- 📭 Empty state message
- 🎨 Custom Solo Leveling "System" theme with glow effects

## 🛠️ Tech Stack
- **React** — UI library
- **TypeScript** — type safety
- **CSS** — custom styling with CSS variables
- **Vite** — build tool

## 📚 What I Learned
- Managing state with the useState hook
- Immutable state updates (spread, map, filter)
- Conditional rendering with ternary operators
- TypeScript types for props and state
- Building a full CRUD application from scratch

## 🚀 Getting Started
```bash
npm install
npm run dev
```
